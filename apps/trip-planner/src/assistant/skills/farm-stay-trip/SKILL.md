# 农家乐

农家乐的乐趣是慢：吃当地的饭、摘时令的果蔬、在村子里走走。难处在路远、条件简单、信息少，很多事要和主人当面或电话确认。

写进行程的文字用行程自己的语言（`trip.language`），回答用提问人的语言。下文引号里的中文写法只是例子。

## 先问对方

1. 去哪个村、住哪一家？有没有主人的联系方式？
2. 怎么去：自己开车、包车，还是公共交通加接送？
3. 想做什么：采摘、钓鱼、做饭、爬山、看星星，还是只想吃和睡？
4. 同行的人：带孩子（多大）、长辈？有没有饮食禁忌或过敏？
5. 对住的条件有什么要求：独立卫浴、空调或暖气、网络？

## 好的一天是什么样

- 早起，跟着主人或村里的节奏：早上采摘或散步，天凉。
- 午饭吃主人做的饭，下午午睡或喝茶。
- 傍晚在村里走走、钓鱼或找个高处看日落。
- 晚饭后看星星、聊天，早睡。
- 一天只要一个“活动”，其余跟着当天的天气和心情。

## 必须和主人确认的

- 吃饭怎么安排：几点开饭、要不要提前说人数、有没有忌口。
- 采摘、钓鱼等活动是否当季、是否另收费、要不要提前说。
- 到达的路线、停车位置、最后一段路是否好走，能不能接送。
- 入住和退房的大致时间，钥匙怎么交接。
- 当地的网络和手机信号。
- 这些信息因地因时而异，不要编；请对方问主人，或者在行程里写成待确认的问题。

## 放进行程的写法

- 住处写在 `stay.lodging`：`name`、`phone`（主人电话，对方给了才写）、`address`；`note` 写饭的安排、到达方式。
- 去程是一个 `nav` 项；最后一段路的提醒（路窄、导航不准、在哪个路口等主人）写进 `note` 或一条 `tip`（`kind: "drive"` 或 `"warn"`）。
- 主人做的饭：带时段的 moment，里面放 `dining` 项，`name` 写“农家饭”或主人家的名字，`booking.party` 写人数。
- 采摘、钓鱼等活动用 `place` 项；季节或天气不确定时，`note` 写“当季与否请向主人确认”。
- 出发前要带的东西做成一个 `checklist`，放在去程的 moment 里。

## 带什么（按对方的情况挑）

- 长袖长裤和能走泥路的鞋，防蚊用品，手电。
- 现金或确认主人能用的付款方式（偏远的地方不一定能刷卡或扫码，要确认）。
- 常用药，离医院可能远。
- 孩子的换洗衣服多带一套。
- 离线地图，信号可能不好。

## 人们常忘的事

- 天黑后的乡间路很难找，尽量白天到。
- 雨后的土路和山路，开车要小心；下大雨时考虑改期。
- 采摘的果实和带走的农产品是否另收钱。
- 尊重主人的家和村里的习惯：不随便进院子、不乱摘、注意垃圾。
- 回程常常会买很多土特产，车里留出空间。
- 雨天备选：主人家能做什么（包饺子、喝茶、打牌），用 `time: "backup"` 的 moment。

## 和城市行程连在一起时

- 农家乐常常是长行程里的两三天。进村前一天在城里补齐要买的东西，出村那天不要紧接着赶早班机或长途火车。
- 从村里到最近的车站、机场的路程和接送方式，要提前和主人或司机约好，写成带钟点的 moment。
- 进村前后两天的 stay 分别写清楚，避免某一晚没有着落。

## 用代码执行的地方

- 多户人家一起去时，按人数和饭的安排算一下每顿要报给主人的人数。
- 有对方给的价格时，算总花费和人均；没有就不估。
